# slaveandcustomer


# ☕ Задача: система учёта заказов в кофейне

Напиши консольную программу на Python, которая хранит меню напитков, принимает заказы и учитывает остатки ингредиентов (порций). Данные должны сохраняться в файл `coffee_shop.json`, чтобы после перезапуска программы меню и заказы не терялись.

## Меню (Каталог)
У каждого напитка должны быть:
*   уникальный ID;
*   название;
*   цена за порцию;
*   остаток порций на складе.

При первом запуске создай несколько напитков, например:
*   `1 — Эспрессо, 150 ₽, остаток 100 порций`
*   `2 — Капучино, 250 ₽, остаток 80 порций`
*   `3 — Латте, 280 ₽, остаток 60 порций`

## Меню программы
Пользователь может выбрать действие:
1. Показать меню (каталог).
2. Создать заказ.
3. Показать все заказы.
4. Изменить статус заказа.
5. Показать отчёт.
6. Завершить программу.

## Создание заказа
Пользователь вводит напитки и их количество. Программа должна:
*   проверить, что напиток существует;
*   проверить, что количество — положительное целое число;
*   проверить, что порций достаточно на складе;
*   рассчитать стоимость каждой позиции и итоговую сумму;
*   уменьшить остаток порций;
*   присвоить заказу уникальный номер.

Применяй скидку ко всему заказу:
*   от 1 000 ₽ — скидка 5%;
*   от 3 000 ₽ — скидка 10%;
*   если сумма меньше 1 000 ₽ — без скидки.

Применяется только одна скидка — наибольшая подходящая.

## Статусы заказа
У заказа должен быть один из статусов:
*   Новый;
*   Выполнен;
*   Отменён.

Пользователь может изменить статус. Если заказ отменяется, порции из него нужно вернуть на склад. Повторная отмена или повторное выполнение заказа не должны повторно менять остатки и отчёты.

## Отчёт
Покажи:
*   общее количество заказов;
*   количество новых, выполненных и отменённых заказов;
*   сумму выручки по выполненным заказам;
*   самый популярный напиток (по количеству проданных порций);
*   текущие остатки порций по каждому напитку.

## Технические требования
*   Раздели программу на функции: например, `показать_меню()`, `создать_заказ()`, `изменить_статус()`, `показать_отчёт()`.
*   Сохраняй и загружай данные из JSON-файла.
*   Обрабатывай неверный ввод и отсутствующий файл без аварийного завершения программы.
*   Не используй сторонние библиотеки.
